2. 配置環境:
   cp .env.example .env
   # 編輯 .env 設置 JWT_SECRET 等

3. 啟動服務:
   docker compose up -d

4. 驗證部署:
   curl http://localhost:8080/health

5. 運行測試:
   ./test-api.sh
