# 數碼管位選驅動電路（高邊驅動 + 速度補償電容）

## 📋 概述

此文檔描述 ESP32 控制 3 位共陽極數碼管的位選驅動電路，採用：
- **NPN + PNP 達林頓對管**：實現 5V 高邊驅動（ESP32 3.3V GPIO → 5V COM 輸出）
- **速度補償電容**：消除 PNP 關斷延遲導致的鬼影（殘影）

    Q1B --> Q1[("S8050<br/>NPN")]

| **0.1μF 電容（104）** | **陶瓷** | **3** | **速度補償，消除鬼影（C1×3）** |

| 場景 | 三極管 | 電阻 | 電容 |

## ⚡ 工作原理

### GPIO 為 HIGH（位選有效）

```
ESP32 GPIO13 = 3.3V
        │
        ▼
S8050 基極 = 0.7V    ← 通過 10kΩ 限流，足夠驅動
S8050 導通
        │
        ▼
S8050 集電極 ≈ 0V    ← 飽和導通
        │
        ▼
2N5401 基極 ≈ 0V    ← 通過 1kΩ 拉低
2N5401 導通
        │
        ▼
2N5401 集電極 ≈ 5V  ← COM1 高電平，該位被選中
```

### GPIO 為 LOW（位選關閉）

```
ESP32 GPIO13 = 0V
        │
        ▼
S8050 基極 = 0V
S8050 截止
        │
        ▼
2N5401 基極 = 5V    ← 通過 10kΩ 上拉到 5V
2N5401 截止
        │
        ▼
2N5401 集電極 = 高阻 ← COM1 無電壓，該位關閉
```

## 🐛 鬼影問題（沒有速度補償電容時）

**現象**：數碼管亮起時，背景一直有微弱的「888」殘影。

**原因**：PNP 三極管 2N5401 從導通到截止有「儲存時間」（storage time）：
1. 截止時，10kΩ 通過寄生電容給基極充電到 5V，需要時間（μs 級）
2. 在這段過渡時間裡，PNP 仍處於部分導通狀態
3. 切換到下一位時，上一位還沒完全關斷，導致兩位同時微弱點亮
4. 累積三位掃描，所有段都會被「點亮一點」，看起來像背景 888

## ✨ 速度補償電容（Speed-up Capacitor）解決方案

在 **2N5401 基極上拉的 10kΩ 電阻兩端並聯一個 0.1μF 陶瓷電容**：

```
2N5401 基極 ─┬─── 10kΩ ───┬─── +5V
             │             │
             └─── 0.1μF ───┘
                  (104)
```

### 為什麼有效？

電容對直流（穩態）相當於開路，所以**不影響工作點**。

但在切換瞬間：
- **PNP 截止瞬間**：電容直接把基極電壓快速拉到 5V，比走 10kΩ 快約 **100 倍**
- **PNP 導通瞬間**：S8050 拉低基極時，電容先放電，提供更大的瞬間拉低電流，**導通也更快**

雙向都加速，是教科書級的標準做法。

### 加裝方法

每個 PNP 的 10kΩ 上拉電阻兩端，並聯 1 個 **0.1μF（104）陶瓷電容**：

```
COM1 通道：在 R6 (10kΩ) 兩端並聯 C1 (0.1μF)
COM2 通道：在 R12 (10kΩ) 兩端並聯 C2 (0.1μF)
COM3 通道：在 R18 (10kΩ) 兩端並聯 C3 (0.1μF)
```

**總計新增 3 個 0.1μF 陶瓷電容**，總成本不到 5 毛錢。

## 🛡️ 抗干擾增強（24V 馬達環境必加）

當馬達在 24V 高電流環境下 PWM 運行時，電源軌和地線會有高頻紋波和瞬態干擾。光靠速度補償電容還不夠，建議加上以下兩項：

### A. 5V 電源去耦電容（C4 + C5）

在 ESP32 的 5V 引腳附近並聯：
- **100μF 電解電容（C4）**：濾低頻紋波（馬達 PWM 帶入的 1kHz 級干擾）
- **0.1μF 陶瓷電容（C5）**：濾高頻噪聲（開關瞬間的 MHz 級毛刺）

```
+5V ──┬───────────────┬─── 5V 電源軌
      │               │
      C4              C5
    100μF           0.1μF
      │               │
      └───────────────┴─── GND
```

**佈線要點**：
- 兩個電容**緊貼 ESP32 5V 引腳擺放**（離得越近越好）
- 地線單點接到主 GND，避免地環路
- 電解電容的正極對 5V，負極對 GND（**極性不能搞錯**）

### B. GPIO 下拉電阻（R0、Rseg）

ESP32 GPIO 在啟動瞬間和切換瞬間會短暫處於**高阻態**，這時引腳電壓會浮動，可能誤觸發數碼管段或位。

```
ESP32 GPIO ──┬─── 後續電路（10kΩ 限流 → S8050 等）
             │
            10kΩ R0
             │
            GND
```

**作用**：
- 啟動瞬間，當 GPIO 還沒配置為 OUTPUT 時，10kΩ 把腳位穩定下拉到 GND
- 切換瞬間，避免邏輯電平浮動誤觸發
- 對段選引腳尤其重要（段引腳高阻時可能導致數碼管段微弱發光）

**佈線要點**：
- 每個位選引腳（GPIO13/5/4）對 GND 加 1 個 10kΩ → 共 3 個
- 每個段選引腳（GPIO23/25/26/27/32/33/14）對 GND 加 1 個 10kΩ → 共 7 個
- 不影響正常工作（10kΩ 對 ESP32 GPIO 來說是非常輕的負載）

### C. 為什麼 USB 模式下沒問題

USB 5V 由電腦穩壓電源供給，紋波極小（mV 級）；24V 馬達電源經過 Mini 560 降壓後，紋波在百 mV 級，並且馬達 PWM 開關會通過 GND 耦合到 ESP32。所以 24V 模式下這些抗干擾措施才會凸顯效果。

## 🔧 完整改造步驟（從基礎版到抗干擾版）

如果您現在的電路只有「PNP 高邊驅動」沒有任何電容，建議按優先級依次改造：

| 優先級 | 改造項目 | 元件 | 效果 |
|-------|---------|------|------|
| ⭐⭐⭐ | 速度補償電容（C1×3）| 3 × 0.1μF | **消除鬼影**（最明顯）|
| ⭐⭐⭐ | 5V 電源去耦（C4+C5）| 100μF + 0.1μF | 馬達 PWM 干擾消失 |
| ⭐⭐ | 位選下拉電阻（R0×3）| 3 × 10kΩ | 啟動瞬間穩定 |
| ⭐⭐ | 段選下拉電阻（Rseg×7）| 7 × 10kΩ | 段引腳穩定，避免微亮 |
| ⭐ | 基極上拉減小（10kΩ→2.2kΩ）| 替換已有電阻 | 開關更快（替代方案）|

實際工作中，前兩項（C1 + C4/C5）就能解決 90% 的干擾問題；後兩項是「精益求精」級別的改進。

## 💡 替代方案：使用專用驅動 IC

如果想簡化電路、提高可靠性，可考慮使用專用驅動 IC：

### 方案 A：ULN2803（達林頓陣列，低邊驅動）

**特點**：
- 8 通道達林頓 NPN，每通道最大 500mA
- 內建續流二極管
- 適合驅動**共陰極**數碼管的位選

**缺點**：
- 是低邊驅動，需要把數碼管改為共陰極
- 或者用於段選驅動（共陽極時）

**接法（用於共陰極位選）**：
```
ESP32 GPIO ─→ ULN2803 IN ─→ ULN2803 OUT ─→ 數碼管 COM
                                            (共陰極，OUT 拉低時點亮)
```

### 方案 B：MIC2981（PNP 陣列，高邊驅動）⭐

**特點**：
- 8 通道 PNP 高邊驅動
- 每通道最大 500mA
- **直接替代我們的 S8050+2N5401+電阻+電容方案**

**接法（直接適用於現有共陽極數碼管）**：
```
ESP32 GPIO ─→ MIC2981 IN ─→ MIC2981 OUT ─→ 數碼管 COM
                                            (共陽極，OUT 拉高時點亮)
```

**對比**：
| 項目 | 分立元件方案 | MIC2981 方案 |
|------|------------|-------------|
| 元件數量 | 9 個三極管 + 18 個電阻 + 3 個電容 | 1 個 IC |
| PCB 面積 | 大 | 小 |
| 可靠性 | 中 | 高 |
| 鬼影 | 需要速度補償電容 | 內部已優化 |
| 成本 | ~3 元 | ~5 元 |

### 方案 C：UDN2981（同 MIC2981）

UDN2981 是 MIC2981 的另一個型號，引腳兼容，可以直接互換。

### 升級建議

- **目前方案**（S8050 + 2N5401 + 速度電容）：適合 DIY/原型開發，成本最低
- **MIC2981 / UDN2981**：適合量產或追求可靠性
- **ULN2803**（如果改共陰極）：適合段選驅動
