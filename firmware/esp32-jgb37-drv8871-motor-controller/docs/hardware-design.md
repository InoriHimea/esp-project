# ESP32 暖菜旋轉盤馬達控制器 — 硬件設計文檔

## 1. 專案概述

本設計將 ESP32 馬達控制器集成到一個**暖菜旋轉盤**中，通過摩擦桌面實現自動旋轉。

### 1.1 設備結構

```
┌──────────────────────────────────┐
│        玻璃面（上方）              │ ← 暖菜加熱面 60-80°C
├──────────────────────────────────┤
│        發熱絲 + 鋁箔              │ ← 加熱元件
├──────────────────────────────────┤
│        22-25mm 空間               │ ← 電路安裝區
│  ┌─────────────────────────────┐ │
│  │ 原廠暖菜板 + ESP32 控制電路  │ │
│  └─────────────────────────────┘ │
├──────────────────────────────────┤
│        雲母隔熱片                 │ ← 隔熱 + 電氣絕緣
├──────────────────────────────────┤
│        耦合器（5 觸點）           │ ← 旋轉供電
├──────────────────────────────────┤
│        固定底座                   │
└──────────────────────────────────┘
```

### 1.2 核心參數

| 項目 | 規格 |
|------|------|
| 旋轉盤直徑 | 約 70mm |
| 固定盤直徑 | 約 35mm |
| 盤內空間高度 | 22-25mm |
| 旋轉方式 | 馬達摩擦桌面帶動 |
| 供電方式 | 雙溫控耦合器（5 觸點同心圓）|
| 原廠功能 | 暖菜（可調溫度）|
| 新增功能 | WiFi 馬達控制 + 溫度監控 |


## 2. 電源方案

### 2.1 方案選型：24V 外接電源 + 5 觸點耦合器

經過多方案對比，最終選擇**安全性最高**的方案：

| 方案 | 安全性 | 成本 | 複雜度 | 結論 |
|------|--------|------|--------|------|
| 220V 進入盤內 + HLK-PM24 | ⚠️ 中 | 73 元 | 中 | ❌ 有觸電風險 |
| 帽蓋滑環 + 24V | ✅ 高 | 60 元 | 中 | ⚠️ 機械改造大 |
| DIY 銅環觸點 | ✅ 高 | 31 元 | 高 | ⚠️ 需手工精度 |
| **5 觸點雙溫控耦合器** | **✅ 極高** | **31 元** | **低** | **✅ 最終選擇** |
| 電池供電 | ✅ 高 | 100 元 | 中 | ❌ 鋰電池高溫風險 |

### 2.2 耦合器規格

選用：**雙溫控耦合器（無繩水壺底座連接器）**

| 參數 | 數值 |
|------|------|
| 觸點數 | **5 路同心圓** |
| 觸點直徑 | 0.8 / 1.7 / 2.6 / 3.6 cm |
| 額定電壓 | 250V AC |
| 額定電流 | 10-15A/路 |
| 旋轉角度 | 360°（任意方位）|
| 雙溫控 | 95°C 自復位 + 105°C 熔斷 |
| 成本 | 8 元/套 |
| 淘寶搜索 | 「雙溫控耦合器」 |

### 2.3 觸點分配

```
路 1（外環 Φ36mm）：220V L   → 原廠暖菜板
路 2（環 Φ26mm）：  220V N   → 原廠暖菜板
路 3（環 Φ17mm）：  保護地 PE → 安全隔離緩衝
路 4（環 Φ8mm）：   24V+     → ESP32 馬達控制系統
路 5（中心點）：    24V-     → ESP32 馬達控制系統
```

安全設計：220V（路 1-2）和 24V（路 4-5）之間隔了 PE 地線（路 3），物理距離 ≥ 9mm。

### 2.5 旋轉不纏線原理

耦合器的同心圓觸點設計使得：
- 公頭（凸觸點）固定在旋轉盤底面，**跟盤一起轉**
- 母頭（彈簧片）固定在底座頂面，**不轉**
- 上盤的線焊在公頭背面，**永遠在盤內部**，不會纏繞
- 底座的線焊在母頭背面，**完全靜止**


## 3. 隔熱設計

### 3.1 雲母隔熱片

原廠在耦合器上方安裝了一片**雲母片（Mica Sheet）**：

| 特性 | 數值 |
|------|------|
| 材質 | 天然雲母（白雲母）|
| 耐溫 | 500-700°C |
| 熱導率 | 0.4-0.6 W/m·K（隔熱優秀）|
| 絕緣強度 | 20-30 kV/mm |
| 厚度 | 0.5-1mm |
| 形狀 | 圓形，帶 3 個固定孔 |

### 3.2 雲母片的雙重作用

1. **熱絕緣**：阻擋玻璃面熱量傳到耦合器和底座
2. **電氣絕緣**：防止 220V 加熱絲漏電穿透到低壓區

### 3.3 安裝位置

```
發熱絲 + 鋁箔（高溫區）
       ↓
   電路區（ESP32 等）
       ↓
━━━ 雲母片 ━━━  ← 隔熱層（必須保留！）
       ↓
   耦合器公頭
```

### 3.4 溫度估算

| 位置 | 預計溫度 | 安全餘量 |
|------|---------|---------|
| 玻璃面 | 60-80°C | - |
| 電路區（冷區，無發熱絲覆蓋）| 40-55°C | ESP32 上限 85°C，餘量 30°C |
| 雲母片下方 | 35-45°C | 耦合器安全 |
| 底座 | 25-35°C | 完全安全 |

### 3.5 注意事項

- ⚠️ 替換耦合器時**必須保留雲母片**
- ⚠️ 如果新耦合器螺絲位置不同，需在雲母片上重新打孔
- ⚠️ 雲母片損壞時可淘寶購買替代品（搜「圓形雲母片 隔熱」）

| 參數 | 數值 |
|------|------|
| 型號 | JGB37-520 |
| 額定電壓 | 24V DC |
| 空載轉速 | 45 RPM |

| 堵轉電流 | 約 2.5A |

### 4.2 驅動方案

| 參數 | 數值 |
|------|------|
| 驅動 IC | DRV8871 |
| 驅動模式 | IN/IN（雙 PWM）|
| PWM 頻率 | **1 kHz**（降低頻率解決驅動問題）|
| PWM 分辨率 | 10 bit（0-1023）|
| 默認最大速度 | 70%（700/1023）|
| 默認 ramp 時間 | 2000ms（慢啟動，保護電源）|
| GPIO IN1 | GPIO18 |
| GPIO IN2 | GPIO19 |

### 4.3 PWM 頻率選擇說明

原始設計使用 20kHz，但實測發現 DRV8871 無法正確響應。
經測試確認：
- 直接 GPIO HIGH/LOW → 馬達正常旋轉 ✅
- 20kHz PWM → 馬達不轉 ❌
- **1kHz PWM → 馬達正常旋轉 ✅**

最終選擇 1kHz，DRV8871 推薦範圍內。

## 8. 安裝步驟

### 8.1 拆解原廠

1. 拆下旋轉盤上層
2. 拆除原廠耦合器（保留螺絲和支架）
3. **保留雲母隔熱片**（重要！）
4. 記錄原廠接線（拍照）

### 8.2 安裝新耦合器

1. 確認新耦合器尺寸是否匹配原廠位置
2. 如果螺絲孔位不同，在雲母片上重新打孔
3. 安裝順序（從下到上）：
   - 底座 → 母頭固定 → 雲母片 → 公頭固定到盤底

### 8.3 接線

**底座側（母頭背面）**：
```
路 1 端子 ← 220V L（從牆插）
路 2 端子 ← 220V N（從牆插）
路 3 端子 ← PE 地（接機殼）
路 4 端子 ← 24V+（從外接電源）
路 5 端子 ← 24V-（從外接電源）
```

**旋轉盤側（公頭背面）**：
```
路 1 端子 → 220V L → 原廠暖菜板
路 2 端子 → 220V N → 原廠暖菜板
路 3 端子 → PE 地 → 原廠地線 + ESP32 GND
路 4 端子 → 24V+ → 自恢復保險絲 → 24V 主軌
路 5 端子 → 24V- → GND 軌
```

### 8.4 盤內電路連接

```
24V 主軌 ──┬── 1000μF/35V（正極朝 24V+）
           ├── 0.1μF 陶瓷
           ├── TVS SMBJ24A
           ├── DRV8871 VCC → 馬達
           └── Mini 560 IN → 5V OUT → ESP32 VIN
```

### 8.5 測試流程

| 步驟 | 操作 | 預期結果 |
|------|------|---------|
| 1 | 萬用表測通斷（不通電）| 5 路各自獨立，無短路 |
| 2 | 旋轉一圈測通斷 | 每路持續導通 |
| 3 | 只接 24V，不接 220V | ESP32 啟動，馬達可控 |
| 4 | 接 220V | 原廠暖菜板正常工作 |
| 5 | 同時工作 | 暖菜 + 馬達互不干擾 |
| 6 | 連續運行 1 小時 | 溫度 < 60°C |

## 10. 已知問題與解決方案

### 10.1 數碼管鬼影（已放棄數碼管）

**問題**：24V 供電時數碼管背景有微弱 888 殘影。

**根因**：PNP 高邊驅動 COM 輸出 5.1V，段選 GPIO HIGH 為 3.3V，壓差 1.8V 剛好達到 LED 導通閾值。

**嘗試過的方案**：
- ❌ 速度補償電容（0.1μF 並聯 10kΩ）→ 無效
- ❌ 5V 電源去耦（100μF + 0.1μF）→ 無效
- ❌ 軟件消隱期 200μs → 無效
- ✅ 串聯 1N4148 降壓 → 有效但未實施

**最終決定**：放棄數碼管（安裝位置在箱內無法觀看），改用蜂鳴器 + LED 指示。

### 10.2 DRV8871 PWM 頻率問題（已解決）

**問題**：20kHz PWM 時馬達不轉，OUT1/OUT2 電壓相同。

**根因**：可能是 DRV8871 模塊的信號完整性問題。

**解決**：降低 PWM 頻率到 1kHz，馬達正常工作。

### 10.3 GPIO12 啟動問題（已解決）

**問題**：GPIO12 在 ESP32 啟動時影響 Flash 電壓選擇。

**解決**：將數碼管位選從 GPIO12 改為 GPIO5。

- 改造難度較大，需要 220V 電路經驗

## 12. 安全警告

### ⚠️ 220V 相關

- 220V 接線必須由有經驗的人操作
- 所有 220V 焊點必須用熱縮管包覆
- 220V 和 24V 之間必須保持 ≥ 6mm 物理距離
- 通電前必須用萬用表確認無短路
- 建議在 220V 進線端加裝漏電保護器

### ⚠️ 高溫環境

- 雲母隔熱片必須保留
- 不要使用 PVC/EVA 等低溫材料
- 電解電容選 105°C 額定
- 定期檢查元件是否有變色/鼓包

### ⚠️ 旋轉機械

- 所有元件必須用螺絲或熱熔膠牢固固定
- 大電容等高元件防止離心力脫落
- 連接線必須用扎帶固定，不能晃動
- 定期檢查焊點是否疲勞斷裂
