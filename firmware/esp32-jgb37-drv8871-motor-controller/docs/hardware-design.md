## 1. 最终方案概述

本项目将 ESP32 马达控制系统集成到暖菜旋转盘中，最终采用：

- **4 路工业滑环**：2 路 220V L/N，2 路低压电机通道。
- **上部 800mm 大盘**：电机固定在上盘，通过挖孔沉降让摩擦轮接触桌面并驱动旋转。
- **ESP32/DRV8871 放置**：优先放下盘；空间不足则放外部控制盒。
- **本地指示**：首版只安装 1 颗蓝色 LED，固件和接口预留多色 LED。
- **报警**：加入无源蜂鸣器，用于故障、自检、失联、堵转等提示。
- **检测**：首版加入电压/电流检测；温湿度、防水、霍尔测速仅预留，不进入首版。

### 1.1 结构分层

```text
┌──────────────────────────────────────────────┐
│ 上部 800mm 大盘（旋转）                       │
│  ├─ 原厂暖菜加热面 / 发热丝                   │
│  ├─ 电机 JGB37 固定在上盘                     │
│  ├─ 挖孔沉降：摩擦轮从孔位下探接触桌面        │
│  └─ 220V 加热线 + 电机线经滑环连接            │
├──────────────────────────────────────────────┤
│ 隔热/绝缘层                                   │
│  ├─ 原厂云母片必须保留                        │
│  └─ 电机/电路附近建议追加云母板               │
├──────────────────────────────────────────────┤
│ 4 路工业滑环                                  │
│  ├─ CH1/CH2：220V L/N                         │
│  └─ CH3/CH4：电机低压通道                     │
├──────────────────────────────────────────────┤
│ 下盘 / 外部控制盒（固定，不旋转）              │
│  ├─ ESP32 DevKit                              │
│  ├─ DRV8871 马达驱动                          │
│  ├─ Mini 560 24V→5V                           │
│  ├─ 保护、电压/电流检测、蜂鸣器、蓝色 LED      │
│  └─ 24V 适配器输入 + 220V 输入                 │
└──────────────────────────────────────────────┘
```

### 1.2 核心参数

| 项目 | 规格 |
|------|------|
| 上部旋转盘 | 约 800mm 大盘 |
| 旋转方式 | 上盘电机 + 挖孔沉降摩擦轮 + 桌面摩擦驱动 |
| 滑环 | 4 路工业滑环，5A 级别 |
| 220V 通道 | CH1=L，CH2=N，仅给原厂暖菜发热部分 |
| 低压通道 | CH3/CH4 给电机控制通道 |
| 控制器位置 | 下盘优先；空间不足时外置控制盒 |
| 指示 | 首版 1 颗蓝色 LED，预留红/绿/黄/RGB |
| 报警 | 无源蜂鸣器，多音调/多节奏 |
| 首版检测 | 24V 电压检测、马达电流检测 |
| 后续预留 | 温度、湿度、防水、霍尔测速、多灯位 |

## 2. 4 路工业滑环接线

### 2.1 通道分配

| 滑环通道 | 用途 | 说明 |
|----------|------|------|
| CH1 | 220V L | 固定端进线 → 上盘原厂暖菜板火线 |
| CH2 | 220V N | 固定端进线 → 上盘原厂暖菜板零线 |
| CH3 | MOTOR_A / 低压通道 A | 推荐接 DRV8871 OUT1 → 上盘电机端子 A |
| CH4 | MOTOR_B / 低压通道 B | 推荐接 DRV8871 OUT2 → 上盘电机端子 B |

如果 ESP32/DRV8871 放在下盘或外部控制盒，CH3/CH4 应接 **DRV8871 输出到电机的两根线**，而不是固定 24V+/24V-。这样才能保留 PWM 调速、正反转、刹车、惰行。

如果未来把 ESP32/DRV8871 也放到上盘旋转端，CH3/CH4 才改为传输原始 **24V+ / 24V-** 到上盘控制板。

### 2.2 固定端接线

```text
固定端 / 下盘 / 外部控制盒

220V 输入 L ───────────────→ 滑环 CH1 ─→ 上盘原厂暖菜板 L
220V 输入 N ───────────────→ 滑环 CH2 ─→ 上盘原厂暖菜板 N

DRV8871 OUT1 ─────────────→ 滑环 CH3 ─→ 上盘 JGB37 电机 A
DRV8871 OUT2 ─────────────→ 滑环 CH4 ─→ 上盘 JGB37 电机 B

24V 适配器 ─→ 保护/检测 ─→ DRV8871 VM + Mini560
```

### 2.3 安全要求

- 220V 与低压线在滑环外部必须分束、分色、固定。
- 220V 焊点必须热缩管覆盖，必要时加绝缘胶/三防漆。
- 24V/电机线不要与 220V 线捆在一起。
- 通电前必须万用表确认：CH1/CH2/CH3/CH4 互不短路。
- 建议墙插侧使用漏电保护插座。

## 3. 摩擦驱动机械方案

### 3.1 核心结构

```text
上盘底面（旋转）

        ┌───────────────────────┐
        │      JGB37 马达固定座  │
        │           │           │
        │        马达轴          │
        │           │           │
        │      橡胶/硅胶摩擦轮   │
        └───────────┬───────────┘
                    │
             挖孔沉降区域
                    │
                    ▼
              桌面 / 固定摩擦面
```

电机固定在上部 800mm 大盘上，摩擦轮从挖孔处下探并压在桌面。电机转动时，摩擦轮相对桌面产生切向力，推动整个上盘旋转。

### 3.2 挖孔沉降要求

| 项目 | 建议 |
|------|------|
| 孔径 | 摩擦轮直径 + 4~8mm 间隙 |
| 孔边 | 倒角/打磨，避免割伤轮胎和线缆 |
| 轮子下探量 | 静态下压 1~2mm，保证接触但不过度压紧 |
| 马达固定 | JGB37 支架 + M3 螺丝 + 防松垫片/螺纹胶 |
| 轮子材料 | 橡胶/硅胶，优先高摩擦、耐热、不掉屑 |
| 轮径 | 20~35mm 先试装，根据转速和扭矩调整 |
| 轮宽 | 8~15mm，过窄易打滑，过宽阻力大 |

建议让马达固定座有少量弹性补偿，例如薄硅胶垫、弹簧片或可调高度垫片。桌面不可能完全平整，刚性压死会导致打滑、噪音或电流尖峰。

### 3.3 线缆斜坡 / 线缆桥

摩擦轮经过桌面线缆时会出现跳动、卡顿、瞬时堵转。首选方案是让 220V/24V 外部线缆完全避开摩擦轮轨迹；无法避开时，必须做低坡度线缆桥。

#### 3.3.1 结构目标

```text
侧视图：

桌面 ───────╱￣￣￣￣╲─────── 桌面
            ╱  线缆槽  ╲
           ╱   cable    ╲
          ╱______________╲

摩擦轮行进方向 →
```

```text
俯视图：

摩擦轮轨迹  ───────────────→

          ┌─────────────────────┐
          │      缓坡上升区      │  L1
线缆方向  │════════线缆槽════════│
          │      缓坡下降区      │  L2
          └─────────────────────┘
```

#### 3.3.2 尺寸公式

设线缆束直径为 `D`：

- 线缆桥最高点 `H = D + 2mm`。
- 坡度角 `θ <= 8°~10°`。
- 单侧坡长 `L >= H / tan(θ)`。
- 顶部平直段 `T = 15~25mm`。
- 总长度 `Total = 2L + T`。

示例：线缆直径 `D=6mm`，取 `H=8mm`：

| 坡度 | 单侧坡长 L | 总长估算 |
|------|------------|----------|
| 10° | ≥45mm | ≥110mm |
| 8° | ≥57mm | ≥135mm |
| 6° | ≥76mm | ≥175mm |

建议首版做 **总长 150~180mm** 的缓坡，宁可长，不要陡。

#### 3.3.3 宽度与槽位

| 项目 | 建议 |
|------|------|
| 桥体宽度 | 摩擦轮宽度 × 2 + 20mm，通常 40~60mm |
| 线缆槽宽 | 线缆束直径 + 2~4mm |
| 线缆槽深 | 线缆直径的 40%~60%，不要完全压扁线缆 |
| 表面 | 细纹/磨砂，避免太光滑导致摩擦轮打滑 |
| 固定 | 低残胶双面胶、硅胶垫、可移胶，不能在桌面滑动 |

#### 3.3.4 材料选择

| 材料 | 评价 |
|------|------|
| TPU 95A | 推荐，弹性好，不易伤线缆，3D 打印可行 |
| 硅胶/橡胶 | 推荐，摩擦力好，耐热较好 |
| PETG/ABS | 可用，需在表面贴防滑橡胶条 |
| PLA | 不推荐，靠近暖菜设备可能软化变形 |
| 金属 | 不推荐直接接触线缆，除非外包绝缘层 |

#### 3.3.5 测试流程

1. 先不通 220V，仅通 24V。
2. 低速运行，让摩擦轮连续跨越斜坡 20 次。
3. 观察上盘是否跳动、摩擦轮是否打滑、线缆桥是否移位。
4. 读取电流检测值；跨越斜坡时不应出现持续过流。
5. 若有明显卡顿：降低坡度、增大总长、换更软材料、或调整线缆走向。

## 4. ESP32/DRV8871 放置建议

### 4.1 下盘优先

优点：

- 不随上盘旋转，维护方便。
- 散热更好。
- WiFi 信号更稳定。
- 电压/电流检测、蜂鸣器、LED 更容易外置。

注意：

- 下盘/外部控制时，滑环 CH3/CH4 应是 DRV8871 OUT1/OUT2 到电机。
- ESP32、DRV8871、Mini560、传感模块必须共地。

### 4.2 外部控制盒

如果下盘空间不足，建议把 ESP32/DRV8871/Mini560/蜂鸣器/LED 放外部控制盒：

- 控制盒开通风孔。
- 24V 输入用 DC 5.5×2.1mm 母座。
- 220V 与低压端子物理分区。
- LED 和蜂鸣器放在外壳可见/可听位置。
- 到下盘的线束使用带锁接插件，避免拉扯脱落。

## 5. 隔热与云母板

### 5.1 是否需要买云母板

**建议购买。** 原厂云母片必须保留，但电机固定在上部大盘后，电机、支架、线缆和滑环附近会更靠近发热区域。额外云母板可作为局部隔热/绝缘补强。

### 5.2 使用位置

| 位置 | 建议 |
|------|------|
| 原厂发热丝与电路区之间 | 保留原厂云母片，不要移除 |
| 电机支架与上盘热源之间 | 加 0.5~1mm 云母板 |
| 220V 接线附近 | 用云母板/耐热绝缘片隔开低压线 |
| DRV8871/ESP32 若放下盘 | 不一定需要云母板，但要保证通风 |
| 外部控制盒 | 一般不需要云母板，重点是通风和绝缘端子 |

### 5.3 云母板规格

- 厚度：0.5~1mm。
- 形状：可裁剪片材，优先买 100×100mm 或 A4 片材。
- 耐温：≥500°C。
- 安装：用螺丝/压片固定，不要只靠普通胶水。
- 注意：云母板是隔热/绝缘件，不是承力结构件。

## 6. 首版指示与报警

### 6.1 蓝色 LED

首版只安装 1 颗蓝色 LED：

| 状态 | 蓝色 LED 行为 |
|------|---------------|
| 停止/待机 | 灭或低频心跳 |
| WiFi/AP 配网 | 慢闪 |
| MQTT 未连接 | 双闪 |
| 运行 | 常亮 |
| 加减速 | 呼吸/慢闪 |
| 刹车/堵转/过流 | 快闪 |
| 自检 | 按测试节奏闪烁 |

### 6.2 多灯位预留

建议预留 3 个 GPIO 焊盘：

| 颜色 | 用途 | 建议 GPIO |
|------|------|-----------|
| 红 | 故障、过流、过温、堵转 | GPIO13 |
| 绿 | 网络正常、运行正常 | GPIO5 |
| 黄 | 配网、自检、警告、降速 | GPIO4 |
| RGB 数据 | WS2812B 扩展 | GPIO32 |

首版可不焊接，只在 PCB/洞洞板/端子上预留焊盘。

### 6.3 蜂鸣器

建议使用**无源蜂鸣器**，由 ESP32 PWM 输出不同音调：

| 场景 | 蜂鸣器模式 |
|------|------------|
| 开机 | 短 beep 一次 |
| 配网成功 | 上升双音 |
| MQTT 断开 | 每 10s 短 beep，或可配置关闭 |
| 过流/堵转 | 急促三连 beep |
| 自检完成 | 两短一长 |
| 严重故障 | 持续间歇报警 |

## 7. 电压/电流检测

### 7.1 24V 电压检测

使用电阻分压到 ESP32 ADC：

- R1：100kΩ 1%，从 24V_PROT 到 ADC。
- R2：10kΩ 1%，从 ADC 到 GND。
- C：0.1µF，从 ADC 到 GND，滤波。
- ADC：GPIO34。

24V 输入时 ADC 约 2.18V；30V 输入时约 2.73V，留有余量。

### 7.2 电流检测

推荐 INA226 高边电流检测模块：

- 比 INA219 更适合 24V 系统。
- I2C 接 ESP32 GPIO21/GPIO22。
- 安装在 24V_PROT 到 DRV8871 VM 之间。
- 可用于堵转、卡线、斜坡阻力、电源异常检测。

## 8. 暂不加入的功能

| 功能 | 首版状态 | 原因 |
|------|----------|------|
| 数码管 | 不采购、不推荐继续使用 | 安装位置不可见，占 GPIO，已有鬼影问题 |
| 霍尔测速 | 暂不做 | 无法在所有面稳定安装磁铁/传感器，上方靠近电炉丝 |
| 温度 | 仅预留 | 4 路滑环通道不足，后期换 6 路或更多再加 |
| 湿度 | 仅预留 | 同上 |
| 防水/漏水 | 仅预留 | 同上 |
| 多色 LED | 预留焊盘/BOM | 首版只焊蓝色 LED |

## 11. 安全警告

### 11.1 220V

- 220V 接线必须由有经验的人操作。
- 220V 焊点必须热缩管覆盖。
- 220V 与低压线保持物理距离。
- 通电前必须万用表测短路。
- 建议使用漏电保护插座。

### 11.2 高温

- 原厂云母隔热片必须保留。
- 电机附近建议追加云母板。
- 不要使用 PLA、PVC、EVA 等低耐温材料靠近热区。
- 电解电容选 105°C 型号。

### 11.3 旋转机械

- 电机固定座必须防松。
- 摩擦轮不可压得过紧。
- 线缆桥必须固定，不能在桌面滑动。
- 大盘连续运行 1 小时后检查电机、DRV8871、滑环、线缆温度。
