## 当前最终方案

- 4 路工业滑环。
- CH1/CH2：220V L/N，供原厂暖菜板。
- CH3/CH4：低压电机通道。
- ESP32、DRV8871、Mini560、保护、电压/电流检测、LED、蜂鸣器优先放下盘；空间不足时放外部控制盒。
- JGB37 电机固定在上部 800mm 大盘，通过挖孔沉降让摩擦轮接触桌面并驱动旋转。
- 如果 ESP32/DRV8871 位于固定侧，CH3/CH4 必须接 DRV8871 OUT1/OUT2 到上盘电机，不应接固定侧原始 24V+/24V-。
- 如果未来把 ESP32/DRV8871 也放到旋转上盘，CH3/CH4 才改为传输原始 24V+/24V- 到上盘控制板。
- 首版只安装 GPIO2 蓝色 LED，预留红/绿/黄/RGB 灯位。
- 加入无源蜂鸣器，推荐 GPIO25 + S8050 低边驱动。
- 加入 24V 电压检测与 INA226 电流检测。
- 霍尔、温度、湿度、防水检测暂不进入首版，只预留后期 6 路或更多滑环方案。
- 3 位数码管已废弃，不再采购、不推荐安装。

## 首版 GPIO 分配

| 功能 | ESP32 GPIO | 状态 | 说明 |
|------|------------|------|------|
| DRV8871 IN1 | GPIO18 | 必需 | LEDC PWM CH0 |
| DRV8871 IN2 | GPIO19 | 必需 | LEDC PWM CH1 |
| 蓝色 LED | GPIO2 | 必需 | 高电平点亮 |
| 蜂鸣器 PWM | GPIO25 | 推荐 | S8050 低边驱动 |
| 24V ADC | GPIO34 | 推荐 | 100k/10k 分压 |
| INA226 SDA | GPIO21 | 推荐 | I2C |
| INA226 SCL | GPIO22 | 推荐 | I2C |
| 红色 LED 预留 | GPIO13 | 预留 | 故障 |
| 绿色 LED 预留 | GPIO5 | 预留 | 正常/联网 |
| 黄色 LED 预留 | GPIO4 | 预留 | 警告/配网/自检 |
| RGB 预留 | GPIO32 | 预留 | WS2812B DIN |
| 温湿度预留 | GPIO33 | 后期 | 更多滑环通道或外置传感器 |
| 漏水预留 | GPIO35 | 后期 | 只能输入 |

避免使用 GPIO12，防止影响 ESP32 启动绑带配置。

## 24V 保护与检测

推荐链路：

```text
24V DC JACK +
  → F1 1.1A hold / 2.2A trip 自恢复保险丝，或 2A 可更换保险丝
  → +24V_PROT
  → TVS SMBJ24A 到 GND
  → 1000µF/35V/105°C 电解 + 0.1µF/100V 陶瓷
  → INA226 VIN+ / VIN-
  → +24V_MOTOR
  → DRV8871 VM
```

电压检测：

```text
+24V_PROT → R1 100kΩ → ADC 节点 → R2 10kΩ → GND
ADC 节点 → R3 1kΩ → ESP32 GPIO34
ADC 节点 → C3 0.1µF → GND
```

24V 输入时 ADC 约 2.18V；30V 输入时约 2.73V。

## LED 与蜂鸣器

蓝色 LED：

```text
ESP32 GPIO2 → 330Ω → 蓝色 LED → GND
```

无源蜂鸣器：

```text
+5V → BZ1 → S8050 C
ESP32 GPIO25 → 1kΩ → S8050 B
S8050 E → GND
S8050 B → 100kΩ → GND（推荐）
```

磁式蜂鸣器建议并联 1N4148/1N4007 续流二极管，阴极接 +5V，阳极接 S8050 集电极。

## 机械与绝缘要点

- 摩擦轮直径建议 20-35mm，宽度 8-15mm。
- 上盘挖孔直径为摩擦轮直径 + 4-8mm 间隙，孔边倒角/打磨。
- 静态下压 1-2mm，保证接触但不过度压紧。
- 线缆应避开摩擦轮路径；无法避开时，使用总长 150-180mm、坡度不超过 8-10° 的线缆桥。
- 原厂云母片必须保留。
- 电机支架、220V 接线、热源附近建议追加 0.5-1mm、耐温 >=500°C 云母板。
