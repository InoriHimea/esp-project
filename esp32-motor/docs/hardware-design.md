## 1. 專案概述

本設計將 ESP32 馬達控制器集成到一個**暖菜旋轉盤**中，通過**馬達中央軸傳動**實現自動旋轉。

### 1.1 設備結構

```
┌──────────────────────────────────┐
│        玻璃面（上方）              │ ← 暖菜加熱面 60-80°C
├──────────────────────────────────┤
│        發熱絲 + 鋁箔              │ ← 加熱元件（保留）
├──────────────────────────────────┤
│        22-25mm 空間               │ ← 電路安裝區
│  ┌─────────────────────────────┐ │
│  │ 原廠暖菜板 + ESP32 控制電路  │ │
│  │      + 馬達 JGB37            │ │
│  └─────────────────────────────┘ │
├──────────────────────────────────┤
│        雲母隔熱片                 │ ← 隔熱 + 電氣絕緣
├──────────────────────────────────┤
│   馬達軸 → 聯軸器 → 滑環公頭     │ ← 中央軸傳動
├──────────────────────────────────┤
│        4 路工業滑環               │ ← 旋轉供電
├──────────────────────────────────┤
│        固定底座                   │
└──────────────────────────────────┘
```

### 1.2 核心參數

| 項目 | 規格 |
|------|------|
| 旋轉盤直徑 | 約 70mm |
| 固定盤直徑 | 約 35mm |
| 盤內空間高度 | 22-25mm |
| **旋轉方式** | **馬達中央軸驅動（直接驅動）** |
| **接地** | **無接地（雙絕緣設計）** |
| **供電方式** | **4 路帽式工業滑環（5A）** |
| 原廠功能 | 暖菜（可調溫度，保留）|
| 新增功能 | WiFi 馬達控制 + 溫度監控 |


## 2. 方案演進歷史

### 2.1 已評估方案對比

| 方案 | 安全性 | 成本 | 改造難度 | 機械可行性 | 結論 |
|------|--------|------|---------|-----------|------|
| 220V 進入盤內 + HLK-PM24 | ⚠️ 中 | 73 元 | 中 | ✅ | ❌ 觸電風險 |
| 雙溫控耦合器（5 觸點同心圓）| ✅ 高 | 31 元 | 低 | ⚠️ **電氣安全問題** | ❌ 220V 與 24V 隔離不足 |
| DIY 銅環觸點 | ✅ 高 | 31 元 | 高 | ✅ | ⚠️ 手工精度要求高 |
| **車輪摩擦桌面方案** | ✅ 高 | 31 元 | 中 | ❌ **桌面有電源線會卡輪子** | ❌ 不平穩 |
| **4 路工業滑環 + 中央軸傳動** ✅ | **✅ 極高** | **~98 元** | **中** | **✅ 工業標準** | **✅ 最終選擇** |

### 2.2 為什麼放棄燒水壺式耦合器

雖然 5 觸點雙溫控耦合器（8 元/套）價格便宜，但存在**嚴重的電氣安全隱患**：

1. **同心圓觸點隔離不足**
   - 220V 路和 24V 路在同一個耦合器內
   - 環間距 4-5mm，遇到塵土或潮濕可能跨距放電
   - 沒有 CCC 認證

2. **無獨立絕緣設計**
   - 220V 觸點短路時可能影響 24V 系統
   - 24V 端可能瞬時出現高壓
   - 損壞 ESP32 的風險

3. **長期可靠性問題**
   - 塑料絕緣材料在 220V 下會老化
   - 接觸電阻不穩，220V 大電流下可能發熱

→ **工業滑環是更專業、更安全的選擇**

### 2.3 為什麼放棄車輪摩擦方案

實際安裝環境的限制：
- 桌面上有 **220V 加熱絲電源線**
- 同時要引入 **24V 馬達電源線**
- 兩組線纜在桌面上會**阻礙車輪平穩旋轉**
- 經過電源線時會出現顛簸、卡頓

→ **改為中央軸傳動，盤離開桌面**


## 3. 最終電源方案：4 路工業滑環

### 3.1 滑環規格

| 參數 | 數值 |
|------|------|
| 類型 | 帽式（Capsule）工業滑環 |
| 路數 | **4 路** |
| 額定電流 | **5A/路** |
| 額定電壓 | 240V AC/DC |
| 直徑 | **12.5mm** |
| 工作溫度 | -40~+80°C |
| 壽命 | > 1000 萬轉 |
| 旋轉方式 | 360° 連續旋轉 |
| 採購 | 已採購 ✅ |

### 3.2 觸點分配（無接地版）

由於原機是**雙絕緣設計（無接地）**，4 路足夠用：

```
路 1：220V L  → 原廠暖菜板火線
路 2：220V N  → 原廠暖菜板零線
路 3：24V+    → ESP32 馬達控制系統
路 4：24V-    → ESP32 馬達控制系統
```

### 3.3 安全設計

雖然滑環內部 220V 和 24V 距離較近，但相比同心圓耦合器：
- ✅ **每路獨立金屬環**（垂直堆疊，不是同心圓）
- ✅ **絕緣材料是工業級** PA66 或 PEEK
- ✅ **接觸由獨立彈簧片**，不會跨路導通
- ✅ **CE 認證**

### 3.4 接線圖

```
┌────────── 旋轉盤上層（公頭隨盤旋轉）──────────┐
│                                              │
│   公頭背面 4 條引線：                          │
│      路 1 → 220V L → 原廠暖菜板               │
│      路 2 → 220V N → 原廠暖菜板               │
│      路 3 → 24V+   → 自恢復保險絲 → ESP32 系統│
│      路 4 → 24V-   → ESP32 系統 GND           │
│                                              │
│   所有線焊到公頭背面，跟盤一起旋轉            │
│   → 線不會纏繞                                │
└──────────────────────────────────────────────┘

┌────────── 固定底座（母頭不旋轉）──────────────┐
│                                              │
│   母頭背面 4 條引線：                          │
│      路 1 → 220V L（從牆插）                   │
│      路 2 → 220V N（從牆插）                   │
│      路 3 → 24V+（從外接適配器）               │
│      路 4 → 24V-（從外接適配器）               │
│                                              │
└──────────────────────────────────────────────┘
```


## 4. 機械傳動方案：中央軸直接驅動

### 4.1 核心思路

不再讓盤摩擦桌面旋轉，而是**用馬達直接驅動滑環公頭**，公頭固定在馬達軸上，**馬達轉 = 盤轉**。

### 4.2 結構圖

```
┌──────────── 旋轉盤上層 ───────────────┐
│                                       │
│  ESP32 + DRV8871 + 控制電路           │
│         │                             │
│   24V   ↓                             │
│         │                             │
│  ┌──────┴──────┐                      │
│  │  馬達固定座  │                      │
│  │  + JGB37    │                      │
│  │     ↓       │                      │
│  │   軸 6mm    │                      │
│  └─────┬───────┘                      │
│        │                              │
│   彈性聯軸器（吸收偏心）                │
│        │                              │
└────────┼──────────────────────────────┘
         │
   ┌─────┴─────┐
   │ 滑環公頭  │ ← 跟著馬達旋轉
   │ Φ12.5mm  │
   └─────┬─────┘
         │ ← 同心圓觸點接觸面
   ┌─────┴─────┐
   │ 滑環母頭  │ ← 固定在底座
   │ Φ12.5mm  │
   └─────┬─────┘
         │
┌────────┴──────────────────────────────┐
│                                       │
│  底座（不旋轉）                        │
│  + 24V 適配器接入                      │
│  + 220V 接入                           │
│                                       │
└───────────────────────────────────────┘
```

### 4.3 為什麼選擇直接驅動（對比皮帶/齒輪）

| 方案 | 成本 | 噪音 | 維護 | 結論 |
|------|------|------|------|------|
| **直接驅動（聯軸器）** ✅ | **10-15 元** | **無** | **零維護** | **首選** |
| 皮帶輪傳動 | 30 元 | 低 | 皮帶會老化 | 適合需要減速比 |
| 齒輪傳動 | 25 元 | 中 | 需潤滑 | 適合大力矩 |

### 4.4 速度控制

JGB37-520 (45 RPM) 通過 PWM 軟件調速：

| PWM 占空比 | 馬達轉速 | 應用場景 |
|-----------|---------|---------|
| 100% (1023) | 45 RPM | 最快，調試用 |
| 70%  (700)  | 31 RPM | 默認上限 |
| **50%  (512)** | **22 RPM** | **暖菜推薦速度** ⭐ |
| 30%  (307)  | 13 RPM | 慢速展示 |
| 20%  (204)  | 9 RPM  | 超慢速 |

### 4.5 聯軸器選型

選用 **彈性聯軸器（梅花式）**：

```
   ┌─────────┐
   │ 馬達軸6 │ ← 馬達側（JGB37 軸 6mm）
   └────┬────┘
        │
   ┌────┴────┐
   │ 梅花橡膠│ ← 彈性塊吸收震動 + 補償偏心
   │  彈性塊 │
   └────┬────┘
        │
   ┌────┴────┐
   │滑環軸6mm│ ← 滑環側
   └─────────┘
```

**規格要求**：
- 兩端內徑：6×6mm（馬達 6mm + 滑環軸 6mm）
- 外徑：12-15mm
- 長度：20-25mm
- 允許偏心：1-2mm
- 允許角度偏差：1-2°

**淘寶搜索**：「彈性聯軸器 6×6mm」、「梅花聯軸器 6mm」  
**價格**：8-15 元

| 耐溫 | 500-700°C |

### 5.1 雙重作用

1. **熱絕緣**：阻擋玻璃面熱量傳到滑環和底座
2. **電氣絕緣**：防止 220V 加熱絲漏電穿透

### 5.2 安裝位置

```
電路區（ESP32 等）
       ↓
━━━ 雲母片 ━━━  ← 必須保留！
       ↓
   滑環公頭（馬達軸帶動）
       ↓
   滑環母頭（固定底座）
```

⚠️ **拆解時必須保留雲母片**，丟失後可採購替代品（淘寶搜「圓形雲母片 隔熱」）。

## 10. 安裝步驟

### 10.1 拆解原廠

1. 拆下旋轉盤上層
2. 拆除原廠耦合器（保留螺絲和支架）
3. **保留雲母隔熱片**（重要！）
4. 記錄原廠接線（拍照）

### 10.2 機械改造

#### 步驟 1：固定馬達到上盤底面
```
上盤底面 ──┬── 馬達固定座（M3 螺絲）
           │
           └── JGB37 馬達（卡入固定座）
                     ↓
                  軸 6mm 朝下
```

#### 步驟 2：安裝聯軸器
```
1. 把彈性聯軸器一端套到馬達軸（6mm）
2. 用 M2 螺絲固定聯軸器到馬達軸
3. 另一端準備接滑環公頭軸
```

#### 步驟 3：安裝滑環公頭
```
1. 滑環公頭軸（6mm）插入聯軸器另一端
2. 用 M2 螺絲固定
3. 公頭背面焊接 4 條引線（後面接線用）
```

#### 步驟 4：固定滑環母頭到底座
```
1. 滑環母頭固定到底座（用支架或 3D 列印件）
2. 母頭背面焊接 4 條引線（接 220V 和 24V）
3. 公母頭對接，測試旋轉是否順暢
```

#### 步驟 5：軸對齊測試
```
1. 慢慢轉動上盤，觀察是否抖動
2. 聽是否有異響
3. 如有問題，調整聯軸器位置或更換墊片
4. 彈性聯軸器允許 1-2mm 偏心，調試容錯較大
```

### 10.3 電氣接線

#### 旋轉端（公頭）
```
公頭背面 4 個焊接點：
  ├─ 路 1 → 220V L → 進入上盤的 220V 接線盒 → 原廠暖菜板
  ├─ 路 2 → 220V N → 進入上盤的 220V 接線盒 → 原廠暖菜板
  ├─ 路 3 → 24V+ → 自恢復保險絲 → 1000μF/0.1μF 並聯 → 24V 主軌
  └─ 路 4 → 24V- → ESP32 GND 軌

24V 主軌 ──┬── DRV8871 → 馬達
           └── Mini 560 → 5V → ESP32

注意：所有焊線跟著公頭一起旋轉，永遠在上盤內部，不會纏繞！
```

#### 固定端（母頭）
```
母頭背面 4 個焊接點：
  ├─ 路 1 → 220V L（從牆插）
  ├─ 路 2 → 220V N（從牆插）
  ├─ 路 3 → 24V+（從適配器）
  └─ 路 4 → 24V-（從適配器）

底座外接：
  - 220V 牆插
  - 24V/2A DC 適配器（DC 5.5×2.1mm 母座）
```

## 12. 已知問題與解決方案

### 12.1 數碼管鬼影（已放棄數碼管）

**問題**：24V 供電時數碼管背景有微弱 888 殘影。

**根因**：PNP 高邊驅動 COM 輸出 5.1V，段選 GPIO HIGH 為 3.3V，壓差 1.8V 剛好達到 LED 導通閾值。

**最終決定**：放棄數碼管（安裝位置在箱內無法觀看），改用蜂鳴器 + LED 指示。

### 12.2 DRV8871 PWM 頻率問題（已解決）

**問題**：20kHz PWM 時馬達不轉。

**解決**：降低到 **1kHz**，馬達正常工作。

### 12.3 GPIO12 啟動問題（已解決）

**問題**：GPIO12 影響 Flash 電壓選擇。

**解決**：將數碼管位選從 GPIO12 改為 **GPIO5**。

### 12.4 燒水壺耦合器電氣安全問題（已避開）

**問題**：5 觸點同心圓耦合器無法在 220V 和 24V 間提供足夠絕緣。

**解決**：改用 4 路工業滑環。

### 12.5 車輪摩擦方案桌面顛簸（已避開）

**問題**：桌面有 220V 和 24V 兩組線纜，車輪會卡住。

**解決**：改為**中央軸傳動**，盤離開桌面。

## 14. 安全警告

### ⚠️ 220V 相關

- 220V 接線必須由有經驗的人操作
- 所有 220V 焊點必須用熱縮管包覆
- 220V 和 24V 之間在滑環和盤內**必須保持物理距離**
- 通電前必須用萬用表確認無短路
- 雖然原機是雙絕緣（無接地），仍建議在牆插端加裝**漏電保護器**

### ⚠️ 高溫環境

- 雲母隔熱片**必須保留**
- 不要使用 PVC/EVA 等低溫材料
- 電解電容選 105°C 額定
- 定期檢查元件是否變色/鼓包

### ⚠️ 旋轉機械

- 馬達必須**牢固固定**（離心力作用）
- 聯軸器螺絲必須擰緊（建議加螺紋膠）
- 大電容等高元件防止離心力脫落
- 連接線必須用扎帶固定，不能晃動
- **不要過載**：JGB37 額定電流 0.5A，避免堵轉

### ⚠️ 電氣安全

- 24V 端子使用 DC 母座，**避免使用裸線連接**
- 上盤 220V 和 24V 連線**用不同顏色**區分
- 焊接後**塗三防漆**（旋轉環境防潮）
